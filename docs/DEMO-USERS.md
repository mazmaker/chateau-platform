# เอกสารบัญชีผู้ใช้ทดสอบ (Demo Users)

**สร้างเมื่อ**: 29 ธันวาคม 2025
**เวอร์ชัน**: 1.0.0
**สำหรับ**: CHATEAU Platform - การทดสอบระบบ

---

## ภาพรวม

เอกสารนี้ประกอบด้วยบัญชีผู้ใช้จำลองสำหรับการทดสอบระบบ CHATEAU Platform บัญชีเหล่านี้สามารถสร้างได้ทันทีผ่านฟีเจอร์ "สร้างบัญชีทดสอบ" ในหน้าจัดการผู้ใช้

---

## รหัสผ่านมาตรฐาน

```
รหัสผ่านสำหรับบัญชีทดสอบทั้งหมด: Demo123456!
```

## วิธีการสร้างบัญชีทดสอบ

### ผ่าน UI (แนะนำ)

1. ล็อกอินด้วยบัญชี **Owner**
2. ไปที่เมนู **จัดการผู้ใช้**
3. คลิกปุ่ม **"ทดสอบ"** (สีเหลือง-อำพัน)
4. เลือกผู้ใช้ที่ต้องการ หรือคลิก **"สร้างทั้งหมด"**
5. รอให้ระบบสร้างบัญชีเสร็จสิ้น

### รหัสผ่านหลังจากสร้าง

รหัสผ่านเริ่มต้นสำหรับบัญชีทดสอบทั้งหมด:
```
Demo123456!
```

## สรุปจำนวนบัญชี

| ตำแหน่ง | จำนวน | รายชื่อ |
|---------|-------|----------|
| เจ้าของ (Owner) | - | ใช้บัญชีจริงของคุณ |
| แอดมิน (Admin) | 2 | สมชาย ใจดี, นภา สุขใจ |
| พนักงานขาย (Sales) | 3 | วิภาดา รักษ์ดี, ปิติ มั่งมี, กิติ เก่งกาจ |
| **รวมทั้งหมด** | **5** | บัญชีทดสอบทั้งหมด |

## เหตุผลของการใช้ชื่อไทย

การใช้ชื่อผู้ใช้ภาษาไทยมีจุดประสงค์เพื่อ:

1. **ทดสอบการรองรับภาษาไทย** - ตรวจสอบว่าระบบแสดงชื่อภาษาไทยได้ถูกต้อง
2. **จำลองสถานการณ์จริง** - เนื่องจาก CHATEAU Platform เป็นแพลตฟอร์มสำหรับตลาดไทย
3. **ทดสอบ Initials** - ตรวจสอบว่าระบบสร้างตัวย่อจากชื่อภาษาไทยได้ถูกต้อง

### ทดสอบ RBAC (Role-Based Access Control)

| ฟีเจอร์ | Owner | Admin | Sales |
|---------|-------|-------|-------|
| จัดการผู้ใช้ | ✅ | ✅ | ❌ |
| ตั้งค่าบริษัท | ✅ | ✅ | ❌ |
| จัดการทรัพย์สิน | ✅ | ✅ | ✅ |
| จัดการลูกค้า | ✅ | ✅ | ✅ |
| ดูรายงาน | ✅ | ✅ | ✅ |

## หมายเหตุความปลอดภัย

⚠️ **ข้อควรระวัง**:

1. บัญชีทดสอบเหล่านี้มีวัตถุประสงค์เพื่อการพัฒนาและทดสอบระบบเท่านั้น
2. อย่าใช้บัญชีเหล่านี้ในสภาพแวดล้อมการผลิตจริง (Production)
3. ควรเปลี่ยนรหัสผ่านหลังจากการทดสอบเสร็จสิ้น หากจะนำไปใช้จริง
4. ลบบัญชีทดสอบหลังจากใช้งานเสร็จสิ้น
